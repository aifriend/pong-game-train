# CLI Commands

Available commands when using `uv run`:

| Command | Description |
|---------|-------------|
| `uv run pong` | Play the game (short form) |
| `uv run pong-play` | Play the game |
| `uv run pong-train` | Train PPO agent (full curriculum) |
| `uv run pong-eval` | Evaluate trained agent |
| `uv run main.py` | Play the game (entry point) |
| `uv run -m pong` | Play the game (module) |

**Note**: Running `uv run` with no arguments lists available commands. Use one of the above to run the project.
